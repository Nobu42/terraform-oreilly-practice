## この記録について

- 実行結果・会話で確認できた内容と、説明のみで実行を確認していない内容を分けて記載しています。
- 第3章では、ブラウザでDBのアドレスとポートが表示されるところまで確認しました。DBへの実接続テストとは区別しています。
- 学習終了後のWeb・DBの削除完了ログは、記録作成時点では未確認です。
- パスワード、アクセスキー、アカウントID、実際のDBエンドポイントは学習記録に載せていません。
- サンプル中の `<STATE_BUCKET_NAME>` などは置き換え用の表記です。そのまま実行しないでください。
- コードを実行するとAWSリソースが作成されます。書籍の無料利用枠の記載だけを根拠に、現在も無料になるとは判断しないでください。

## Git管理

このリポジトリのルートでまとめて管理し、章ごとに `git init` は行いません。

| Gitに含めるもの | Gitに含めないもの |
| --- | --- |
| Terraformコード、学習用スクリプト、README | 認証情報、パスワード、秘密鍵 |
| 各構成の `.terraform.lock.hcl` | `.terraform/`、Stateとバックアップ、保存済みplan |
| 機密情報のない図 | 秘密を含む変数ファイル・実行ログ・コードを連結したメモ |

除外設定は [.gitignore](.gitignore) を参照してください。
`.gitignore` はすでに追跡中のファイルには遡って適用されません。
また、コードを `cat` で連結した `.txt` にも秘密が残るため、拡張子だけで安全と判断しないことが重要です。

コミット用スクリプトは [git_commit.sh](git_commit.sh) です。`git add -A` でリポジトリ全体を対象にするため、表示された変更内容を確認してから進めます。
